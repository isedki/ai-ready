# Vérification indépendante avant toute livraison (19/11)

VÉRIFICATION AVANT LIVRAISON. Aucun livrable n'est présenté à Issam sans vérification indépendante : brouillon d'email, matrice de flux, analyse de MC, fiche, rapport, et tout code destiné à son Mac. Un sous-agent vérificateur (contexte neuf, modèle standard) reçoit le livrable et contrôle chaque affirmation : la source existe et dit cela mot pour mot si c'est entre guillemets ; elle porte sur le MÊME sujet (même projet, même composant, même personne) ; dates, heures, IP, ports, noms et destinataires (p-annuaire) exacts ; message lu en entier, corbeille comprise, jamais seulement l'aperçu. Pour le code : ce qui a été exécuté ici et ce qui ne peut l'être que sur le Mac est écrit en toutes lettres avant de le donner. Les KO sont corrigés avant la livraison ; ce qui reste non vérifiable est signalé à Issam en une ligne. Le passage le note (« vérifié : n OK, n corrigés, n non vérifiables »).
