# mode d'emploi et adresses des outils

Ce document fait foi pour toutes les tâches programmées Phénix. En cas de contradiction avec le texte d'une tâche, c'est lui qui prime ; une règle plus récente d'Issam s'ajoute ici (nouveau chunk ou ligne datée), jamais dans le texte des tâches.
Chaque passage démarre sans mémoire : l'état est dans les outils, pas dans la conversation.
- Suivi : https://claude.ai/artifact/TuQrD8fCas29vz1YkzWQji, collections `actions` (une action = a0xx / A-0xx, avec faits datés `events`), `paths` (chemin critique), `politique`, `recette`, `tracker_atos`, `stats`, `jour` (un document par jour AAAA-MM-JJ : objectifs du jour, brouillons proposés, questions en attente, ce qui a été fait par chaque passage).
